## How work flows through ClientFlow

```
Lead → Deal → Proposal (internal approval → client decision)
     → Project (tasks, time, deliverables, change requests)
     → Invoices and payments
```

- **Sales** adds leads, moves deals through the pipeline and prepares proposals.
- A **sales manager** approves each proposal version before the client sees it.
- The **client** accepts, declines or asks for changes in the portal. Accepting marks the deal as won.
- A won deal becomes a **project**, run by a project manager (PM) with team members.
- **Finance** issues invoices and records payments.
- **Owner/Admin** manage the team, settings, imports and system status.

## Signing in

- Accounts are created by invitation only: there is no public sign-up.
- Open the invitation link, choose a password (at least 12 characters; very common passwords are
  refused), and you are signed in.
- **Forgot password?** on the sign-in page sends a reset link. The link works once and expires.
- Sessions end after 12 hours without activity, or 7 days at most. Signing out ends the session on
  that device.

## Phones and accessibility

- Every page works from 360 px wide. Wide tables scroll inside their own box, never the whole page.
- Everything can be done with a keyboard. **Skip to content** is the first stop on every page.
- On the task board, each card also has a status menu, so you never need to drag.

## Getting help

- Error messages include a short **request ID**. Send it to your Owner or Admin: it finds the exact
  event in the logs without sharing any of your data.
