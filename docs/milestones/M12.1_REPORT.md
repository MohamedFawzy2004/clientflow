## Authorization and negative testing evidence

- Before setup, a required role can only read its session, sign out and set up: `GET /contacts` and `POST /contacts` answer 403 `MFA_SETUP_REQUIRED`. Other roles are unaffected.
- **No session before the code.** A wrong code is 422. A replayed code is refused. Five wrong codes end the challenge, even if a right code follows. An expired challenge is 401.
- A recovery code works once.
- Required roles cannot turn two-step sign-in off (403). Admins cannot reset others (403). Owners cannot reset themselves (403).
- An infected upload is not stored (422, audited with the signature). An unreachable scanner refuses the upload (503) and nothing is stored.
- Resend logs never contain the recipient, the link or Resend's error message.

5. Run `node scripts/staging-check.mjs --base https://… --email …` and keep the output.
